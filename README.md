# Enterprise Work Assistant

NVIDIA AI CAMPUS 팀 프로젝트 — LLM을 활용한 기업 업무지원 서비스

## 프로젝트 소개

기업 업무에서 발생하는 반복 작업과 정보 확인의 부담을 줄이기 위한 LLM 기반 서비스를 개발합니다. 자연어로 작성된 문서와 메시지의 맥락을 이해하고, 사용자가 업무에 활용할 수 있는 결과를 제공하는 것을 목표로 합니다.

> 현재는 주제 선정 및 기획 단계입니다. 아래 아이디어는 검토 중인 후보이며, 최종 주제와 구현 범위, 기술 스택은 팀 회의를 통해 결정합니다.

## 목표

- 구체적인 사용자와 업무 상황을 정의합니다.
- 해당 업무에서 LLM이 필요한 역할을 명확히 합니다.
- 확보 가능한 데이터와 개발 기간에 맞춰 핵심 기능을 구현합니다.
- 원문 근거와 사람이 검토할 수 있는 결과를 제공합니다.
- 평가 사례를 통해 결과의 정확성과 업무 활용 가능성을 확인합니다.

### 구체화한 제안: RFP 요구사항 분석 및 설계 점검

IT 프로젝트의 제안요청서(RFP)와 작성한 기능 목록을 비교해, 구현 전에 요구사항의 반영 여부를 검토하도록 돕는 서비스입니다. 현재 구체화한 후보이며, 팀의 확정 주제는 아닙니다.

**제안 배경**

팀원의 SI 프로젝트 경험에서, 초기 분석과 설계가 불명확할 때 구현·시험 단계에서 요구사항을 재확인하거나 기능을 다시 개발하는 상황이 발생했습니다. 이 경험을 바탕으로, 구현 전에 누락 가능성과 불명확한 사항을 확인하는 도구를 제안했습니다. 재작업 감소 효과는 검증이 필요한 가설입니다.

**예상 사용 흐름**

1. 텍스트형 RFP와 간단한 기능 목록을 입력합니다.
2. 요구사항, 조건, 제약과 원문 근거를 추출합니다.
3. 각 요구사항에 대응하는 기능을 연결합니다.
4. 대응 근거 발견, 부분 반영 후보, 근거 미발견 항목을 검토표로 제공합니다.
5. 사용자가 원문을 확인하고 연결 관계와 기능 목록을 수정합니다.

**LLM의 역할**

- 문장과 표에 담긴 요구사항을 구조화합니다.
- 표현이 다른 요구사항과 기능의 의미를 비교합니다.
- 반영 근거가 부족한 항목과 추가 확인 질문을 제시합니다.

실제 구현 누락을 자동으로 단정하지 않습니다. 입력 문서에서 확인한 근거와 모델의 추론을 구분하고, 최종 판단은 사람이 수행합니다.

**차별성 가설**

문서 분석과 비교는 범용 LLM에도 요청할 수 있습니다. 이 제안은 요구사항·원문·대응 기능을 함께 보여주고, 항목별 수정과 반복 점검을 지원하는 업무 흐름에 초점을 둡니다. 동일한 입력과 기준을 사용한 기본 프롬프트 결과와 비교해 효과를 검증할 계획입니다.

**초기 범위 제안**

- 텍스트형 RFP 1개와 짧은 기능 목록
- 요구사항 추출과 대응 기능 연결
- 원문 근거 및 확인 필요 항목 표시
- 사용자 검토와 수정

설계 전체 자동 생성, 코드 생성, OCR, 외부 업무 시스템 연동은 초기 범위에서 제외하는 것을 제안합니다.

**향후 확장 아이디어**

- 검토한 요구사항을 바탕으로 설계 초안 제안
- 요구사항과 테스트 항목을 연결해 검증 누락 점검
- 요구사항 변경 시 관련 설계·기능·테스트의 영향 범위 확인

향후 확장 기능은 이번 개발 범위에 포함하지 않으며, 문서 간 연결 정보 관리와 정확성 검증이 필요합니다.
